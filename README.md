# Nafplio School of Finance & Business — site

Bilingual (EL/EN) single-page site. Static — no build step.

## Deploy on GitHub Pages
1. Create a new repository and add `index.html` (from this `site/` folder) to the root.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, folder `/root`.
3. Your site goes live at `https://<username>.github.io/<repo>/` within a minute.
4. (Optional) Add a custom domain under the same Pages settings.

## Notes
- Fonts load from Google Fonts; everything else is self-contained.
- Name, partner institution, figures and contact are **placeholders** — edit the text in `index.html` (and the `dict` object in the script for the Greek/English strings).
